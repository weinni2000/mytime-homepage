1. Install the module — demo data with five sample nodes is loaded automatically.
2. Go to **Orbital Timeline → Timeline Items** to manage nodes.
3. For each item set: title, display date, description, icon, status, energy (0–100),
   and the connected nodes (many2many to other items).
4. The `Sequence` field controls the clockwise order of nodes on the orbit.
5. Visit `/orbital_frontend_view` to see the live orbital timeline.
